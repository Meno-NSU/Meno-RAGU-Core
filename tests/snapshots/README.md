# Снимок графового конвейера

`pipeline_snapshot.json` фиксирует результат `RaguRagPipeline.prepare()` на
миниатюрном корпусе и ответах из `tests/ragu_fakes.py`. Модели и серверы не
нужны. Проверяются контекст документов и графа, источники, пользовательская
инструкция QA и сведения об этапах. Системное время и длительности в снимок
не включаются.

При намеренном изменении формата сначала проверьте различия, затем обновите
снимок на той же входной реплике из `tests/conftest.py` и выполните весь набор
тестов. Снимок не заменяет проверку качества на полной базе знаний.
