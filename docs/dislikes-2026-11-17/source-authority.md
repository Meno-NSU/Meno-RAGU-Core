# Авторитет источников в RAGU, 17.11.2026

Ответ на дизлайки «Как поступить в НГУ?» и «Как поступить на ФИТ?»: в источниках почти одни посты VK и Telegram. Первая причина — неполная коллекция фрагментов стенда; её исправили утром 17.11 (см. README этой папки). Здесь вторая причина и её исправление (ветка `feat/source-authority`).

## Что было не так
1. **Порядок кандидатов.** Он считался как логарифм шансов (логит) итоговой оценки плюс вес × ln(качество источника), как в Меноне 1.1.
   - Метки LLM-переранжирования у стенда насыщаются в 1.0, кросс-энкодер — около 0.99, а логит растягивает этот край.
   - Поэтому разница оценки поиска 0.999 против 0.997 весила больше, чем авторитет 0.55 (пост) против 0.90 (страница nsu.ru).
   - Так `nsu.ru/n/education/apply/` с оценкой LLM 1.0 стояла 13-й и не попала в 12 фрагментов контекста, а семь постов попали.
2. **Шкала качества.** У документов из KB v3.8 качество по шкале KB: посты около 0.55, новости 0.45–0.6, страницы НГУ 0.8–0.9. У корпуса графа (nsu-v1) шкала своя, сжатая в 0.70–0.80.
   - Его посты VK получили 0.77, Pure — 0.75, страницы nsu.ru — 0.73.
   - Для тех же страниц оценки KB: 0.60, 0.60 и 0.90.
3. **Источники ответа** выбирались только по оценке кросс-энкодера, без авторитета.

## Что изменено
- **Приоритет кандидата:** ln(итоговая оценка) + вес × ln(качество), то есть релевантность × качество^вес. Вес по умолчанию 1. При почти равной релевантности решает авторитет, явно более релевантный пост остаётся впереди.
- **Одна шкала качества:** `document_quality.json` рядом с корпусом стенда (`scripts/stand_document_quality.py`, `meno_rag.stand.quality`). Документ получает:
  - оценку KB для той же страницы;
  - иначе медиану KB ближайшего раздела сайта, где в KB не меньше 30 документов;
  - иначе сохраняет свою.
  
  Для стенда v5k изменилось 18 531 документ: посты VK из nsu-v1 0.77 → 0.60, Pure 0.75 → 0.60, справочник НГУ 0.74 → 0.90. Карточки преподавателей и учебные документы не изменились.
- **Источники ответа:** набор прежний (все фрагменты, с которыми хотя бы одно предложение ответа набрало ≥ 0.5), но порядок — по оценке × качество^вес. При отсечке в 5 источников первыми уходят посты, которые подтверждают ответ не лучше официальной страницы.
- **`GRAPH_CHANNEL=false`:** только поиск по фрагментам, без графового канала, для замера вклада графа. По умолчанию граф включён.

## Замеры, без судьи
**Выбор контекста.** 322 вопроса из 558 с эталонной страницей, стенд v5k с полной коллекцией. Переписывание, поиск и LLM-переранжирование прогнаны один раз, контекст для каждого варианта выбран заново из тех же оценок (`final1116/authority/authority_sim.py`).

**Источники ответа.** 110 ответов нового кода: 81 вопрос с эталоном и 29 дизлайков RAGU с 16.11. Варианты отбора сравнивались на одних и тех же ответах (`attr_offline.py`).

На 29 дизлайках выбранный вариант даёт 20% постов против 25%. «Лучший на предложение» отброшен: он терял эталонную страницу в 11 ответах.

«Как поступить в НГУ?», новый код:

- источники: `nsu.ru/n/education/apply/`, priem.nsu.ru, english.nsu.ru/admission, ciep.nsu.ru/postuplenievngu и один пост (было 5 постов).

## FRIDA или bge-m3 для текстового поиска RAGU
Проверка на одном корпусе: документы KB v3.8, общие для обоих индексов. 157 вопросов с эталоном в этой части, исходная формулировка вопроса (`final1116/frida_cmp/`).

| Поиск | RAGU (bge-m3) hit@10 | Менон (FRIDA) hit@10 | Разница, 95% ДИ |
|---|---:|---:|---|
| Только векторы | 0.682 | 0.682 | 0.000 [−0.064; +0.064] |
| Гибрид с BM25 | 0.711 | 0.713 | −0.002 [−0.053; +0.049] |
| Гибрид + кросс-энкодер | 0.752 | 0.783 | −0.032 [−0.076; +0.013] |

Значимой разницы моделей нет: менять эмбеддер не нужно.

Каждая система по своему корпусу — другое дело: hit@10 0.710 у RAGU против 0.777 у Менона, −0.067 [−0.112; −0.026]. Разрыв сосредоточен на 112 вопросах, где эталонная страница есть в стенде только в старой копии из корпуса графа: копию KB v3.8 при сборке стенда убрали как дубль. Следующий шаг — индексировать для текстового поиска текст KB v3.8 таких страниц.
