## Пример: «Какие самые старые факультеты в НГУ?»

Даты в ответе верны: ФЕН — 1959, ФФ и ММФ — 1961, ГФ и ГГФ — 1962, ЭФ — 1967. Плохи источники (три поста «ФЕН — значит первый!») и рамка «один самый старый». Менон на тот же вопрос показывает страницы истории физфака и НГУ, хронику и очерк Лисса.

1. **Поиск.**
   - Запросы — четыре перефраза одного вопроса.
   - Страниц истории ФЕН и физфака нет даже в пуле из 860 фрагментов, хотя в корпусе они есть.
2. **Переранжирование.**
   - Страницы истории отдельных факультетов (Гуманитарного института, ГГФ, ММФ) получили 0.5, то есть «частично относятся к вопросу о всех факультетах». Посты получили 0.9999.
   - Из 12 мест: 4 поста, 3 фрагмента PDF олимпиады СУНЦ по химии (ошибка LLM) и одна страница nsu.ru.
   - «История НГУ» с оценкой 0.99 не прошла: у неё ниже оценка поиска.
3. **Граф.**
   - Поиск по сущностям вернул 4 дубля «НГУ» и случайные «старейшие» (Нижний Новгород, клуб «Гея»).
   - У сущностей факультетов описания засорены. У ГГФ — кто там учился и одно предложение трижды.
   - Историй ФЕН и физфака в графе нет: эти страницы KB добавлены только в поиск по фрагментам (v3k).

## Что предлагаем — общие механизмы, без правил под вопросы

1. **Отбор контекста по общей полезности вместо «сначала метка, потом оценка поиска».**
   - Непрерывная оценка: вероятность «относится» по logprobs, со шкалой «отвечает / полезный контекст / не по теме». Авторитет и свежесть источника — множителями.
   - Штраф за повтор одного документа, одного типа источника или одной сущности (MMR).
   - Нижний порог вместо добивки до 12. Кандидат оценивается против подзапроса, который его нашёл.
   - Проверка: 538 целевых вопросов, Meno Eval v1 и эти 27 дизлайков.
2. **Даты для всех документов** (из текста и метаданных KB) — в промпте и в оценке свежести.
3. **Источники ответа** — по тем же оценкам авторитета и свежести, только из фрагментов выше порога, без источников при отказе.
4. **Пул поиска.**
   - Модель разбора вопроса пишет варианты запроса в терминах корпуса и видит окрестность найденных сущностей в графе, чтобы решить, по каким искать отдельно.
   - Перед LLM — дешёвое предранжирование кросс-энкодером по топ-200.
   - Ветка `fix/engine-cross-encoder-scores` — единая шкала оценок движка.
5. **Данные.**
   - Граф v6: v5 плюс официальные страницы KB; сборка идёт 17.11.
   - Скачать рабочие программы курсов по ссылкам индексов.
   - Сервисы кампуса и навигация; команды программ.
6. **Промпт ответа.** Нейтральные подписи документов (название, сайт, дата) вместо «DOCUMENT N» и «ЭЛЕМЕНТЫ ГРАФА ЗНАНИЙ». Маршрут для опечаток с переспросом вместо отказа.
