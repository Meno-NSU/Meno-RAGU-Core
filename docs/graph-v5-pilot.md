# Граф v5: разметка по онтологии НГУ — пилот (12.11.2026)

Граф заново не извлекается: каждый узел v4 получает тип онтологии `code/graph_utils/ontology/nsu.yaml` и вид
(named, concept, vague, role, identifier, garbled), каждая связь — тип из тех, что онтология допускает между новыми
типами её концов (в любую сторону), или RELATED_TO, если текст связи называет факт, для которого типа нет. Текст
связи сохраняется всегда. Размечает gemma-4-12B-it (Everest :9022), скрипты — `code/ontology_labelling/`, версия
подсказки и модель записаны в каждой метке. Применяет метки этап очистки (`--graph_entity_subtypes`,
`--graph_relation_retypes`, `graph_cleanup.py`): узлы-роли, идентификаторы, расплывчатые фразы и испорченные имена
становятся частью описаний соседей, как значения.

## Найдено по ходу: обрезка имён (исправлено, 7f6fbfe)

`canonicalize_artifacts` (этап 06) срезал по краям имени любую пунктуацию — и закрывающую скобку или кавычку, чья
пара внутри имени: «Дексаметазон (DEX)» → «Дексаметазон (DEX», «[Re6−xMoxSe8(CN)6]n» без «[», названия
конференций без «»». Извлечение (этапы 02–05) давало имена целыми. В v4 так испорчено **22 299 узлов (5,8%)**.
Сборка v5 пересчитывает этап 06 и получает целые имена; входы очистки, сделанные на v4, находят узлы по имени с
точностью до пунктуации и регистра.
