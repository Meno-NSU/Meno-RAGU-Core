исправлены, как менялась сборка и чем всё измерено. Числа взяты из логов сборок, отчётов аудита и прогонов на сервере meno.

### Пробел данных и вариант v3k

На 558 вопросах с эталонной страницей (324 вопроса): страница есть в базе Менона v3.8 для 320, а в корпусе графа — только для
196. Для 125 (39%) страница есть лишь в базе Менона: в корпусе графа 22,7 тыс. адресов против 180,6 тыс. в базе.

Вариант **v3k** закрывает пробел без извлечения графа: 171 774 документа базы v3.8, которых нет в корпусе графа (579 816 чанков,
434 904 уникальных по тексту), добавлены только в поиск по чанкам (векторы bge-m3 + BM25), коллекция чанков — 632 622 точки
(`kb_extend.py`). Граф v3k тот же, что у v3.

исключённых чанков — файлы, входящие в отпечаток сборки; их можно отменить, пересобрав с другими файлами.

### Инцидент с диском (12 ноября, 00:16 UTC)

При записи векторов v3 диск сервера заполнился под Qdrant :6433, тем же, что обслуживает прод-Менон: Qdrant индексирует
большие свежие коллекции во временных копиях сегментов. Прод-коллекции остались зелёными, Менон отвечал. С тех пор:
большие коллекции создаются с выключенной индексацией (`indexing_threshold: 0`, `max_optimization_threads: 1`), индексация
включается по одной коллекции после записи; держим ≥ 50 ГБ свободными; `disk_guard.sh` останавливает тяжёлые задачи, если
свободно меньше 15 ГБ.

## 6. Что не сделано и что дальше

- context_precision у RAGU втрое ниже: в контексте ~20 кусков (до 12 документов и до 3 элементов графа). Следующая доработка —
  строже отбирать документы и элементы графа.
- Не измерены: задержка ответа RAGU, вклад графа (прогон с отключённым графом), попадание в эталонную страницу для v3 и v3k.
- v3k не лучше v3 по правильности; гипотеза — посты соцсетей вытесняют официальные страницы. Проверить разбором проигравших
  вопросов и понизить приоритет постов по уровню документа (P0–P3) и правилу Менона «официальные документы надёжнее постов».
- Собственная онтология (типы для дисциплин, программ, уровней образования): данные — 894 920 связей с `UNFIT`.
- Предложенные моделью удаления связей не применены: сначала проверить точность.
